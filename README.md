# Machine Learning TP2

The notebook implements Principal Component Analysis (PCA) on a small student-grades dataset.

It includes:
- Dataset creation and descriptive statistics.
- Standardization of the features.
- Construction of the correlation matrix.
- Eigenvalue/eigenvector calculation and component selection.
- PCA projection implemented manually.
- PCA using scikit-learn.
- Comparison of the two implementations and visualizations.
- Calculation of the variance retained by the first two principal components.
